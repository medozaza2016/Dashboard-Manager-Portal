Catalog backup

Export services and preferences to a JSON file, or restore them from a previous backup.

When connected, export downloads the current shared D1 catalog. Import validates the backup and restores services, categories, tags, and portal settings to D1. If the database is unavailable, the portal clearly identifies browser-only backups.
